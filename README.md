# 🐾 Patas que Transformam

Projeto acadêmico desenvolvido durante o curso de Análise e Desenvolvimento de Sistemas, com o objetivo de aplicar na prática os conhecimentos adquiridos em desenvolvimento web.

**Importante:** Patas que Transformam é uma ONG fictícia, criada exclusivamente para fins educacionais. O site não representa uma instituição real e não realiza atividades de adoção ou doação.

## Sobre o projeto

A proposta consiste no desenvolvimento de um site institucional para uma organização fictícia voltada à proteção e ao bem-estar animal. A ideia é apresentar informações sobre a ONG, divulgar suas iniciativas e disponibilizar um formulário para pessoas interessadas em colaborar.

Durante o desenvolvimento, foram aplicados conceitos de estruturação de páginas, estilização, interatividade e organização do código, buscando criar uma experiência simples e funcional para o usuário.

## Funcionalidades

* Layout responsivo, adaptado a diferentes tamanhos de tela.
* Navegação entre páginas sem recarregamento completo (SPA).
* Formulário com máscaras, validações e campos condicionais.
* Salvamento de rascunho no navegador.
* Carregamento dinâmico dos estados brasileiros por meio da API do IBGE.
* Código JavaScript dividido em módulos para facilitar a organização e a manutenção.

## Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript (ES6+)
* Vite
* History API
* Fetch API
* localStorage
* API do IBGE
* Git e GitHub
* GitHub Actions

## Publicação

O site está hospedado no GitHub Pages, com o processo de build e deploy automatizado pelo GitHub Actions. A cada atualização na branch `main`, o workflow executa a geração da versão de produção com o Vite e realiza a publicação dos arquivos.

## Aprendizados

O desenvolvimento deste projeto contribuiu para aprofundar os conhecimentos em HTML, CSS e JavaScript, além de proporcionar experiência prática com navegação dinâmica, consumo de APIs, manipulação de formulários e modularização de código.

Também foi possível compreender melhor a importância da organização e da manutenção do código ao longo do desenvolvimento de uma aplicação, além de adquirir experiência com ferramentas de build e publicação de projetos web.
